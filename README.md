# 🎓 Indian Engineering Placement Analytics

An interactive dashboard that explores what drives placement and package (LPA)
across Tier-1, Tier-2 and Tier-3 engineering colleges.

## Features
- 📊 Impact of DSA, CGPA, internships and projects on placement
- 🏫 Branch and college-tier comparisons
- 🧠 Skill benchmark for the 20+ LPA group
- 🔮 Scenario-based DSA-to-package projection (an assumption, not a prediction)
- 💻 Read-only SQL sandbox

## Tech Stack
Python · Pandas · SQLAlchemy · MySQL · Streamlit · Plotly

## Run Locally
pip install -r requirements.txt
python Database.py   # load the CSV into MySQL
streamlit run app.py
